# בדיקת תקשורת Gemini עצמאית — 1.0.0

הכלי פועל מחוץ לנוביו וללא תוספים. קוד האפליקציה לא השתנה: ממתינים לתוצאה חיה לפני שילוב תיקון.

## הפעלה פשוטה במחשב

1. חלץ את קובץ ה־ZIP לתיקייה ופתח `index.html` ב־Chrome או Edge. אין התקנה.
2. הזן את מפתח Gemini שלך בעמוד המקומי. הוא מועבר ישירות לגוגל בכותרת HTTPS, ולא נשמר בדוח או באחסון הדפדפן.
3. השאר את שני המודלים מסומנים. השאר את בדיקת 24 התמונות כבויה בסיבוב הראשון.
4. לחץ **התחל בדיקה**. עד 12 בקשות API קטנות; ייתכן חיוב שימוש ב־API.
5. בסיום לחץ **הורד דוח מסונן** ושלח את `gemini-communication-report.json` בצ'אט. אין צורך לשלוח את המפתח.

עדיף לבדוק ממחשב באותה רשת של הטלוויזיה. הצלחה במחשב אינה מוכיחה שהטלוויזיה או הנגן תקינים.
המפתח נמצא בזיכרון רק למשך הבדיקה; שדה ההזנה מתרוקן. סגור את העמוד בסיום.

## מה נבדק, לכל מודל

| שלב | מה משתנה |
| --- | --- |
| plain_default | בקשת טקסט מזערית, 256 טוקני פלט, חשיבה ברירת מחדל — דומה לבדיקה הישנה באפליקציה |
| plain_budget | אותו סוג טקסט, 4096 טוקני פלט, ללא שינוי בחשיבה |
| plain_low | אותו תקציב פלט, חשיבה נמוכה |
| structured_default | תשובת JSON עם מבנה מחייב, חשיבה ברירת מחדל, 4096 טוקנים |
| structured_low | אותו מבנה JSON, חשיבה נמוכה |
| visual_one | JSON ובדיקת הצבע של תמונת בדיקה מלאכותית אחת |
| visual_24 (לבחירה) | אותה בקשה עם 24 תמונות מלאכותיות; שימוש נוסף ב־API |

רק תשובה שלמה עם `finishReason=STOP`, טקסט גלוי ותוכן בדיקה תואם מסומנת `verified`.
HTTP 200, נוכחות `candidates`, או טקסט חשיבה בלבד אינם הצלחה.
הדוח כולל זמני בקשה/כותרות, נפח בקשה/תשובה, קוד HTTP, סיבת סיום קבועה וספירות טוקנים כשזמינות.
הוא אינו כולל מפתח, תוכן תשובה, טקסטי חשיבה, הודעות שגיאה גולמיות, כתובת IP או מזהי חשבון.
אין העלאה אוטומטית של הדוח.

## אם הדפדפן מציג ״רשת או חסימת CORS״

דפדפן אינו מאפשר להבדיל בוודאות בין CORS, DNS, TLS וכשל רשת. יש גרסת Python עצמאית בלי דפדפן ובלי תלויות חיצוניות, הדורשת Python 3.10 ומעלה:

```sh
python check.py
```

ב־Windows אפשר גם `py -3 check.py`. המפתח מוזן בהסתרה ואינו נכתב לקובץ. לחלופין הכלי קורא את `GEMINI_API_KEY` אם כבר הוגדר.
לתוספת בדיקת עומס: `python check.py --large`. לבדיקת מודל אחד: `python check.py --model gemini-3.6-flash`.
גרסת Python מגדירה זמני המתנה לפעולות הרשת; אלה זמני socket ולא הבטחה לדדליין כולל. גרסת הדפדפן מפעילה דדליין כולל לכל בקשה.
מפתח המוגבל להפעלה מאפליקציית Android יכול להידחות כאן; דחייה כזו אינה מוכיחה כשל במפתח בטלוויזיה.

## סטטוס האימות

- GitHub Actions מספר 40491804853 עבר בהצלחה. בדיקות רגרסיה מקומיות ובדיקות ליבת הדפדפן מכסות כשלי פלט/פרטיות/ביטול/דדליין/תשובה גדולה ומפתח בכותרת בלבד.
- נקודת ה־API החזירה `403 PERMISSION_DENIED` בבדיקת בקרה ללא מפתח. זו אינה הוכחת יצירה מוצלחת.
- אין מפתח משתמש בסביבת הפיתוח. בדיקת חשבון אמיתית עם טקסט/JSON/תמונות עדיין לא הושלמה.
- הלוג מהמכשיר `ghgrM` כבר הראה תשובת טקסט מוצלחת במודל החלופי, אך timeout בבקשת תמונות במודל הראשי.
- מועמדים לבדיקה, לא תיקון מאומת: מגבלת פלט קטנה מדי לבדיקת ברירת המחדל, חשיבה ברירת מחדל וזמינות שונה בין מודלים. יש להשוות דוח חי לפני שינוי האפליקציה.
