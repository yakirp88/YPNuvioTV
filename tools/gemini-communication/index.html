בדיקת תקשורת Gemini

בדיקה עצמאית מחוץ לנוביו: משווים מודלים, חשיבה, JSON ותמונות כדי לזהות היכן הבקשה נעצרת.

המפתח נשאר בזיכרון העמוד ונשלח ישירות לגוגל בכותרת הבקשה. הוא אינו נשמר בקובץ, בדוח או באחסון הדפדפן. העמוד אינו מעלה מידע לשרת אחר.

הבדיקה מבצעת עד 12 בקשות API, או עד 14 עם בדיקת העומס. השימוש עשוי להיות מחויב בחשבון ה־API. נשלחים רק טקסט בדיקה ותמונות שנוצרו בעמוד.

הצלחה דורשת תשובה מלאה ותוכן בדיקה תואם. HTTP 200 לבדו אינו מספיק.

פתח את הקובץ בדפדפן במחשב. אם הדפדפן חוסם את הבקשה, התוצאה תסומן כ״רשת או CORS״; במקרה כזה השתמש בכלי Python המצורף. הצלחה במחשב אינה מוכיחה תקינות ברשת של הטלוויזיה.
